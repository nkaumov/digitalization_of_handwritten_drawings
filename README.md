# Digitalization of Handwritten Drawings

Проект по созданию MVP-системы цифровизации рукописных чертежей.

## Основные документы

- [`docs/tz_mvp.md`](docs/tz_mvp.md) — общее ТЗ проекта: цели, границы MVP, архитектурные принципы, критерии успеха.
- [`docs/dev_plan.md`](docs/dev_plan.md) — детализированный поэтапный план разработки с задачами и результатами.
- [`docs/dev_history.md`](docs/dev_history.md) — журнал выполненных этапов (что уже сделано по факту).
- [`docs/Recorded_decisions_stage_1.md`](docs/Recorded_decisions_stage_1.md) — зафиксированные решения по этапу 1 (документирование).
- [`docs/entities_and_contracts_stage_2.md`](docs/entities_and_contracts_stage_2.md) — результаты этапа 2 (доменная модель и внутренние контракты).

## Как использовать документы

- `tz_mvp.md` — основной источник требований. Изменяется только при согласованном изменении цели/границ MVP.
- `dev_plan.md` — рабочий план реализации. Можно уточнять формулировки задач и декомпозицию.
- `dev_history.md` — обновляется после завершения каждого этапа (фиксируем факт выполнения).
- `Recorded_decisions_stage_<N>.md` — отдельный документ решений для каждого завершённого этапа.

## Текущий статус

- Этап 1 (формализация MVP и правил системы) выполнен.
- Этап 2 (проектирование доменной модели и внутренних контрактов) выполнен.
- Следующий этап по плану: Этап 3 — подготовка структуры проекта и инфраструктуры.

## Локальный запуск

Текущее правило локальной разработки:
- Docker не используется.
- Используются локально установленный MySQL и phpMyAdmin.

Требования:
- Node.js 20+
- Python 3.12+

1. Установка JS-зависимостей из корня:
- `npm run setup`

2. Создание Python-окружения для AI-сервиса:
- `python -m venv apps/ai-service/.venv`
- `apps/ai-service/.venv/Scripts/python.exe -m pip install -r apps/ai-service/requirements.txt`

3. Запуск сервисов в отдельных терминалах:
- `npm run dev:web`
- `npm run dev:api`
- `npm run dev:ai`

4. Проверка после старта:
- frontend: `http://127.0.0.1:5173`
- api health: `http://127.0.0.1:3001/health`
- api v1 health: `http://127.0.0.1:3001/api/v1/health`
- ai health: `http://127.0.0.1:8001/health`

## Принцип ведения проекта

Приоритет на текущем этапе: сначала фиксируем решения и архитектурные контракты, затем реализуем код по согласованному плану, после каждого этапа обновляем историю и отдельный файл решений.
